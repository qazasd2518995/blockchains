# 免費遊戲符號
得分乘以總投注數。

# 賠率表
所有贏分以1為投注倍數。

# 倍數特色
它們都是倍數符號。
- 版面只要出現倍數符號，即可獲得2倍到1000倍的隨機倍數。
- 當不再進行掉落消除時，版面上所有倍數符號的倍數會被加總起來，然後乘上得分作為最終得贏分。

# 超級免費遊戲符號
版面只要觸發免費遊戲且同時出現超級免費遊戲符號，依據出現的數量獲得對應倍數贏分。
- 出現1個超級免費遊戲符號將獲得100倍投注贏分。
- 出現2個超級免費遊戲符號將獲得500倍投注贏分。
- 出現3個超級免費遊戲符號將獲得5000倍投注贏分。
- 出現4個超級免費遊戲符號將獲得25000倍投注贏分。

# 免費遊戲特色
任意4、5或6個免費遊戲符號出現時，觸發15場免費遊戲。
- 免費遊戲特色中，只要有出現倍數符號並得分，加總的倍數將會被累計到總倍數中。
- 只要有任何新的倍數符號出現並且得分，那麼總倍數將會被用來乘上得分。
- 免費遊戲特色中任意出現3、4、5或6個免費遊戲符號，即可再次贏得5場免費遊戲，最多可達100場。

# 倍數升級特色
- 免費遊戲特色中，只要有出現倍數符號並得分，加總倍數前有機會觸發倍數符號升級。
- 倍數符號升級有機會連續觸發多次升級，倍數符號最高可達1000倍。
- 超級免費遊戲特色中，觸發倍數符號升級的機率將會提升。

# 最大贏分
贏分上限為當前押注的25000倍
- 主遊戲中，當前盤面贏分達上限時，將立即結束該次旋轉並派發獎勵
- 免費遊戲特色中，當前盤面贏分達上限時，將立即結束免費旋轉並派發獎勵。

# 購買特色
在主遊戲中以100倍當前押注進行購買，即可馬上觸發免費遊戲特色。
免費遊戲特色中的投注額與觸發免費遊戲特色時相同。
按下旋轉鈕使免費遊戲特色自動開始至場數用盡與獎金發放完畢為止。

# 超級購買特色
在主遊戲中以500倍當前押注進行購買，即可馬上觸發超級免費遊戲特色。
超級免費遊戲特色中的投注額與觸發超級免費遊戲特色時相同。
按下旋轉鈕使超級免費遊戲特色自動開始至場數用盡與獎金發放完畢為止。

# 額外押注
額外的投注為原來的25%啟動時，進入免費遊戲機會提升至原本的2倍
額外押分僅用於功能啟動及機率提升，不計入獎金計算基數。所有獎金皆以原基礎押分計算。

# 神運一擊
在主遊戲中以4000倍當前押注旋轉一次，當出現倍數符號時皆為1000倍。
神運一擊特色中的總押注與觸發神運一擊特色時相同。
按下旋轉鈕使神運一擊特色自動開始至回合結束與獎金發放完畢為止。
購買確認畫面標示本特色只旋轉1局，結果為未得分或最高贏分；每局約有1/6.44機率取得最高贏分。

# 隨處支付規則
最小投注20分。
- 版面上任意位置的相同符號總數量決定可獲得獎金。
若遇任何故障導致遊戲結果無法被判定，則所有贏分與彩金一律不成立。
