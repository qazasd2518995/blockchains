# 金寶寶修正交付 — 2026-09-05

本次整合前幾輪已確認的問題及 final review 的 8 項發現，依使用者要求修正與推送。不是新的全平台零缺陷保證。

## 賽特與先前待交付項目

- 男角分裂球在「消除前後同一轉換」使用一致位置：先生成於被消除的空格，再納入 `posTransform` 掉落。未被女角鎖定的新球會下落；既有鎖定球仍固定。
- 不再以倍率值相同就去除補牌球；只有載荷長度證明內嵌的分裂球才去重，避免真正的新 4x 球被漏掉或產生幻影球。
- 補入固定重現種子、1,000 筆男角技能與 100 筆覺醒序列的盤面重播核對；檢查球數、倍率、位置及原始派彩資料未被轉接改寫。
- 購買免遊的四個 Scatter 分散到四個不同橫排及直欄；保留原本符號數量、入場派彩及免遊次數。
- Loading 水平置中並更新資源快取版本；Blackjack 統計文字可換行、不再省略後半段。
- 未完成的棋牌局返回大廳增加取消／確認提示；不自動棄牌或變更結算規則。
- 水果機小數餘額、最後一注、比大小／收分、停止自動下注與未知回應恢復一併交付；新 `/operations/*` 端點使用操作 UUID 防止同次重試再扣款。
- 控制規則停用與刪除分離、刪除確認、處理中鎖定、舊規則管理、已完成狀態、權限及成功／刷新失敗訊息修正。詳見專項報告。

## Final review 八項修正對照

| 發現 | 修正 |
| --- | --- |
| 轉帳超過兩位小數造成帳目不守恆 | 四個轉帳入口共用金額 schema，服務本身再次驗證，交易前拒絕超精度或超長金額。 |
| 轉帳已提交仍回報失敗、可重送 | 餘額、轉帳紀錄、稽核同一 Serializable 交易；新前端送 UUID，伺服器利用既有轉帳主鍵保存同次操作結果。相同識別碼不同內容拒絕，成功後刷新失敗與未知結果分開提示。 |
| 地雷／爬樓梯無盤面仍下注 | scene-ready 與 context-lost 守門；未就緒禁止下注並提供重新載入。 |
| 開局回應遺失誤加回本地餘額 | 回查 active round 後再查錢包；不能確認時禁止新操作，提供重新同步，不自行宣告回滾。 |
| 登出／重設未撤銷舊 access token | 認證 hook 拒絕空／不符的 session；會員、代理、子帳號重設密碼以同一交易清空 session、撤銷 refresh 並記錄稽核。 |
| 唯讀子帳號顯示寫入按鈕 | 共用前端角色／狀態權限、表單防連點及 API 写入攔截；保留後端最終授權。 |
| H5 場景與語系回呼存取失效元件 | 原回呼局部檢查 node/component 有效性、載入錯誤與場景／語系版本；不使用全域吞錯。新增 `9d2e3r1` bundle 並更新啟動／預載版本。 |
| 權杖刷新無逾時 | Web、Admin、Fruit 的 refresh 請求具有 15 秒 deadline，不永久佔住共用刷新等待。 |

另外在重測時補上：路徑尚未生成或階數改變後，建立按鈕保持停用，避免快速提交未完成預覽。爬樓梯手動同步成功後也清除舊的選格鎖，避免盤面恢復卻仍無法選格。
